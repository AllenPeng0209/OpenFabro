instantiation. Splitting a selected native wire adds a shared node and rebases dependent branches;
removing endpoint drawings keeps named electrical memberships. Electrical wire cuts and segment

affected PCB copper when physical pin memberships change. Alternate drawn paths or shared module
interfaces can keep a network connected; the preview shows the resulting groups. Ambiguous upward
interfaces require an explicit binding. Plain drawing removal preserves named electrical memberships.
