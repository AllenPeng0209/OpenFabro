# Flux length and skew tuning reference

Official pages read on 2026-11-15:

- https://docs.flux.ai/reference/length-and-skew-tuning
- https://docs.flux.ai/Introduction/pcb-editor-shortcuts

The documented workflow is an AI request with a target length/tolerance, reference-net matching,
pair/group skew, bus targets or an explicit stackup delay model. It names trombone (default),
accordion and sawtooth meanders, with arcs where radius permits. Pair tuning keeps the pair together.
The shortcut reference does not establish a dedicated interactive tuning key or standalone dialog.

Implement source-editing Agent tools and reviewable native geometry. A local review dialog may
provide the same deterministic engine; do not claim its pixels match an unobserved Flux dialog.
Length/timing estimates, real native DRC, model review, visual inspection and manufacturing
acceptance remain distinct evidence. No interface name supplies an invented propagation model.
